Programas

  • sherpa-onnx 1.13.8 (k2-fsa) — motor de síntesis compilado a WebAssembly. Apache 2.0. Código fuente: github.com/k2-fsa/sherpa-onnx. Modificación de VOZI: una línea en el cargador para leer los modelos desde el almacenamiento local en vez de un paquete fijo.
  • ONNX Runtime (Microsoft) — incluido en el motor anterior. Licencia MIT. github.com/microsoft/onnxruntime.
  • espeak-ng — conversión de texto a fonemas para las voces ligeras, incluido en el motor anterior. GPL 3.0. Código fuente: github.com/espeak-ng/espeak-ng.
  • Tesseract OCR y tesseract.js-core 7.0.0 — reconocimiento de texto. Apache 2.0. Datos en español «tessdata_best»: Apache 2.0.
  • PDF.js 4.10.38 (Mozilla) — lectura de PDF. Apache 2.0.

Código de VOZI

El código propio de VOZI (interfaz, normalización del español, preparación de tramos, importación y estudio) puede usarse, copiarse y modificarse libremente.

Privacidad

VOZI no tiene anuncios ni analítica. Los documentos se procesan en tu dispositivo (lectura de PDF, OCR y voz). Sin cuenta, todo se guarda solo en el dispositivo.

Si entras con una cuenta, el texto de tus documentos, tus notas, citas, tarjetas, marcadores, progreso y ajustes se guardan también en la base de datos de VOZI (Supabase) para sincronizarlos entre tus dispositivos. Cada cuenta solo puede leer su propia información. El audio y las voces nunca se suben. Puedes cerrar sesión y borrar la copia del dispositivo cuando quieras.
